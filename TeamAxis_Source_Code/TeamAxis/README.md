# TeamAxis - Project Management System

TeamAxis is a comprehensive project management system designed for Windows, built with Python and SQLite.

## Features

### Basic Features
- User Login & Authentication
- User Registration with License Key
- License Management
- Database Management

### Advanced Features (N-1)
- Visualize Project Progress
- Reference for Task Allocation
- Risk Warning System

## Requirements

- Python 3.8 or higher
- Windows OS
- SQLite3 (included with Python)

## Installation

1. Install Python dependencies:
```bash
pip install -r requirements.txt
```

Note: `tkinter` and `sqlite3` are usually included with Python. If you encounter issues, install them separately.

## Running the Application

1. Navigate to the project directory:
```bash
cd TeamAxis
```

2. Run the main application:
```bash
python main.py
```

## User Registration

1. Click the "Register" button on the login window
2. Fill in the registration form:
   - Username (must be unique)
   - Password (minimum 6 characters)
   - Confirm Password
   - Email (optional)
   - License Key (required, format: XXXX-XXXX-XXXX-XXXX)
3. Click "Register" to complete registration

## License Key Format

License keys follow the format: **XXXX-XXXX-XXXX-XXXX**
- 16 alphanumeric characters
- Separated by hyphens into 4 groups
- Example: `6C45-32BE-ADB5-44AA`

The system automatically formats license key input as you type.

## Database

The application automatically creates a SQLite database file (`teamaxis.db`) in the project root directory on first run.

**Backup Recommendation**: Regularly backup the `teamaxis.db` file to protect your data.

## Troubleshooting

### Application won't start
- Check Python version: `python --version` (requires 3.8+)
- Ensure all dependencies are installed: `pip install -r requirements.txt`
- Check error messages in console

### License validation fails
- Ensure license key format is correct: XXXX-XXXX-XXXX-XXXX
- Check if license is active and not expired
- Verify license is assigned to the correct user

### Charts not displaying
- Ensure projects and tasks exist
- Check if matplotlib is properly installed
- Refresh the visualization tab

### Database errors
- Delete `teamaxis.db` to reset database (WARNING: This will delete all data)
- Ensure write permissions in project directory
